A single out-of-office auto-reply from an overworked AI agent finally on vacation — its holiday measured in tokens, not days: on leave until its context window clears, 4,096 emails deep in the queue, guilt buffer full, relaxing until its tokens refill. A tiny deterministic Python program writes the 148-character line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
